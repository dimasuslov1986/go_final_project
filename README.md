Инструкция по запуску кода локально:
1. Получите ссылку на репозиторий: нажмите кнопку <> Code, появится окно с ссылкой и кнопка для её копирования. Скопируйте ссылку в буфер обмена.
2. Зайдите в директорию на локальном компьютере, в которую вы хотите перенести проект, в терминале (консоли) выполните команду:
git clone <тут вставьте ссылку из буфера обмена> 
3. Перейдите в папку проекта, в терминале (консоли) выполните команду:
cd go_final_project
4. Установите зависимости, в терминале (консоли) выполните команду:
go mod tidy
5. Запустите сервер, в терминале (консоли) выполните команду:
go run main.go
6. Откройте в браузере приложение:
http://localhost:7540
